# BYD Harmony Cikupa — Next.js Landing Page

Landing page interaktif untuk BYD Harmony Cikupa menggunakan Next.js App Router, TypeScript, Tailwind CSS, GSAP, Lenis, dan React Three Fiber.

## Menjalankan lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3001`.

## Quality gates

```bash
npm run lint
npm run typecheck
npm run build
```

## Teknologi

- Next.js App Router + TypeScript
- Tailwind CSS v4
- Three.js + React Three Fiber + Drei
- GSAP + ScrollTrigger
- Lenis smooth scrolling

## Fitur utama

- Hero cinematic dengan background BYD M6 dan visual kendaraan 3D interaktif.
- Scroll reveal, parallax, smooth scrolling, hover interaction, dan reduced-motion fallback.
- Katalog kendaraan, test drive via WhatsApp, testimonial carousel, simulasi cicilan, dan kontak dealer.
- Asset runtime tersedia di `public/assets`.
